# @vert-ui/ui

## 0.1.0

### Minor Changes

- First release of vert-ui: 25 components with WCAG AA contrast, keyboard and
  screen-reader support, light/dark theming and a shadcn-compatible registry.

  Includes Button, Input, Textarea, Checkbox, Card, Badge, Alert, Separator,
  Progress, Switch, Tabs, Tooltip, Dropdown Menu, Select, Dialog, Avatar,
  Skeleton, Table, Label, Radio Group, Collapsible, Accordion, Popover, Toast
  and the Field/FieldGroup form wrappers.
